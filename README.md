
# Anorbank Power BI Dashboard

## Project Overview
This project presents a banking data analysis dashboard created with Microsoft Power BI.

## Tools Used
- Microsoft Power BI
- Power Query
- DAX

## Key Features
- Banking data visualization
- KPI monitoring
- Interactive data analysis

## Project File
Open `Anorbank.pbix` in Microsoft Power BI Desktop to explore the dashboard.
